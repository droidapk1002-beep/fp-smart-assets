# fp-smart-assets (thème Nova)

Fichiers CSS / JS / données de **FP-SMART** — thème "Nova" (le même thème
moderne que la Version 1) — hébergés ici pour être servis via
[jsDelivr](https://www.jsdelivr.com/?docs=gh) et consommés par le fichier
`fp-smart-blogger-theme.xml` (une seule page mono-fichier, routée par hash).

URL de base une fois poussé :

```
https://cdn.jsdelivr.net/gh/VOTRE-USER/fp-smart-assets@main/
```

Ne renommez pas les fichiers/dossiers : le thème Blogger fourni référence
ces chemins exacts (css/tokens.css, js/i18n.js, data/db.json, ...).

Notez que `css/` contient déjà le thème Nova : il n'est fourni ici que pour
référence / mise à jour future si besoin — le thème Blogger XML embarque
déjà tout le CSS directement (b:skin), donc ces 3 fichiers CSS ne sont
PAS chargés séparément par Blogger.
